# lstm_battery_predict

Данный проект является результатом работы по учебной практике ИГУ магистратуры "Большие данные и интеллектуальные системы". Разработано для проекта "Анализ телеметрии и предсказание поведения аккумулятора БПЛА".  

Цель проекта - прогнозирование поведения аккумуляторной батареи БПЛА с учётом динамики полёта и внешних факторов для повышения точности оценки остаточного времени полёта.  

## Структура ноутбука
1. Загрузка зависимостей, монтирование диска (при работе в google colab, иначе пропустить), загрузка данных, анализ и построение графиков.
2. Машинное обучение: Baseline (LSTM-модель из рассматриваемой статьи)
3. Машинное обучение: LSTM+Attention (модификация)
4. Машинное обучение: LSTM+MultiHeadAttention
5. Машинное обучение: Seq2seq

## Данные
Данные представляют собой телеметрию полётов за 2017-2024в объеме 398 файлов. В общий доступ для обзора и возможности запуска кода будет добавлен 1 файл.

## Вывод
Реализованная baseline-модель показала совпадение тренда, но наблюдаются выбросы, на некоторых участках расхождения. Модификации улучшили метрики модели и прогноз стал точнее и без выбросов. Модификация seq2seq моделью не удалась.
